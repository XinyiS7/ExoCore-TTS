## 3. 观测结论（客观）

1. **真实文本的已确认失败不再复现**：原 273 字文本最差段 0.206 % / 末尾 −9.9 dB（旧 0.38–0.65 % / −6.1…−7.5 dB）——比旧失败低约 3 dB、密度低约 3 倍；但仍高于旧"干净带"上沿（≤0.18 %）。
2. **漂移是时长驱动的全脚本现象**：每段前半→后半 Δ 为 **+1.6 … +9.0 dB**（拉丁短段 +1.6~+3.9，中文长段 +4~+5.8，单调重复内容 +8~+9）。决定"是否进入饱和"的是**段末尾电平**，不是语言。
3. **边界处仍有饱和残留（重要）**：`cjk41`（12.32 s）与 `mixed121`（12.00 s）在**当前预算内**即可复现失败级贴顶（0.707 % / 0.453 %）；把预算收紧到 30 中文字（`cjk30`，10.24 s）**同样**饱和（0.416 %）——**单调重复内容对任何"长度上限"都更敏感**；真实文本在同长度下明显更温和。
4. **密度参数下界被打破**：单调 CJK 实测 **0.34 s/char**（`cjk30`），超过此前自然文本区间 0.245–0.290 s/char；weight-3 的 0.10 s/单位假设在极端内容下偏乐观。

## 4. 代价与延迟事实（供 M3/M4 计划参考）
